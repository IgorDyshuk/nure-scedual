# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is currently not compatible with SWC. See [this issue](https://github.com/vitejs/vite-plugin-react/issues/428) for tracking the progress.

## Practice Dashboard

The React app reads `src/assets/TimeTable_18_10_2025.csv` at build time, filters out lectures, and shows upcoming practical sessions. Replace that CSV with a new UTF-8 timetable to refresh the data — no manual upload required. Consecutive duplicate практики с одинаковым предметом объединяются в одну запись и помечаются как «двойная пара». Для каждого предмета считается порядковый номер практики, поэтому легко увидеть, какая по счету встреча впереди.

```js

  globalIgnores(['dist']),
  {
    files: ['**/*.{ts,tsx}'],
    extends: [

      // Alternatively, use this for stricter rules

      // Optionally, add this for stylistic rules

        project: ['./tsconfig.node.json', './tsconfig.app.json'],
        tsconfigRootDir: import.meta.dirname,
      },
      // other options...
    },
  },
])
```
## CSV Normalization Service

The project includes a lightweight Express service that accepts CSV uploads, detects their source encoding, and returns UTF-8 normalised content.

- `npm run server` — starts the service on port `4000`
- `POST /api/normalize-csv` — send a multipart form with the field `file`
- JSON response contains the detected encoding, whether conversion was needed, and the UTF-8 CSV payload.

Use `GET /health` for a simple readiness check.


You can also install [eslint-plugin-react-x](https://github.com/Rel1cx/eslint-react/tree/main/packages/plugins/eslint-plugin-react-x) and [eslint-plugin-react-dom](https://github.com/Rel1cx/eslint-react/tree/main/packages/plugins/eslint-plugin-react-dom) for React-specific lint rules:

```js
// eslint.config.js
import reactX from 'eslint-plugin-react-x'
import reactDom from 'eslint-plugin-react-dom'

export default defineConfig([
  globalIgnores(['dist']),
  {
    files: ['**/*.{ts,tsx}'],
    extends: [
      // Other configs...
      // Enable lint rules for React
      reactX.configs['recommended-typescript'],
      // Enable lint rules for React DOM
      reactDom.configs.recommended,
    ],
    languageOptions: {
      parserOptions: {
        project: ['./tsconfig.node.json', './tsconfig.app.json'],
        tsconfigRootDir: import.meta.dirname,
      },
      // other options...
    },
  },
])
```
